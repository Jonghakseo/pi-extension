# Hairline 도형 33종

함수 이름 / React 컴포넌트, 무엇인지, 포인터 반응, `intensity`를 올리면 달라지는 점, 어울리는 화면 순이다. 원문 설명은 `node scripts/hairline.mjs list`로 본다. "어울리는 화면"은 고르는 데 쓰는 참고일 뿐 원본이 정한 용도가 아니다. 설명은 [원본 README](https://github.com/lucasmarkes/hairline#the-figures)(MIT, © Lucas Marques)와 타입 선언을 옮긴 것이다.

## 일반·제품

| 함수 / 컴포넌트 | 무엇 | 포인터 반응 | intensity ↑ | 어울리는 화면 |
| --- | --- | --- | --- | --- |
| `riffle` / `Riffle` | 카드 8장이 꽂힌 트레이 | 포인터 아래 카드가 일어선다. 화살표 키로 넘긴다 | 물결이 더 멀리 퍼진다 | 목록, 문서함, 아카이브 |
| `terrain` / `Terrain` | 받침 위 기둥 81개 | 포인터 주변 기둥이 솟는다 | 솟는 범위가 넓어진다 | 히어로, 데이터 분포 |
| `exploded` / `Exploded` | 4겹으로 분해된 앱 창 | 가로로 틈이 벌어지고 세로로 층을 고른다 | 층이 더 벌어진다 | 아키텍처, UI 구조 설명 |
| `phosphor` / `Phosphor` | 7×7 도트 매트릭스 | 루프를 재생하고 포인터가 칠한 자리에 잔광이 남는다 | 잔광이 오래 남는다 | 디스플레이, 알림, 시그널 |
| `slow` / `Slow` | 게이트를 지나는 컨베이어 위 상자 | 호버하면 시간이 느려진다(멈추지는 않음) | 더 느려진다 | 파이프라인, 처리량, 배송 |
| `turntable` / `Turntable` | 턴테이블 위 블록 | 튕기면 돌고 가까운 90도에 멈춘다 | 관성이 길어진다 | 3D 미리보기, 제품 회전 |
| `keyboard` / `Keyboard` | 60키 키보드 | 포인터 아래 키가 눌리고 이웃 키가 따라 내려간다 | 눌리는 범위가 넓어진다 | 입력, 단축키, 개발 도구 |
| `elevator` / `Elevator` | 열린 승강로 옆 4개 층 | 포인터 높이로 층을 고르면 카가 이동한다 | 카가 빨라진다 | 단계, 등급, 레벨 |
| `phone` / `Phone` | 유리·보드·배터리·셸로 분해된 휴대폰 | 가로로 틈, 세로로 층 선택 | 층이 더 벌어진다 | 모바일 앱, 하드웨어 |
| `laptop` / `Laptop` | 얇은 노트북 | 포인터 높이만큼 덮개가 스프링처럼 열린다 | 더 넓게 열린다 | 데스크톱 앱, 온보딩 |
| `terminal` / `Terminal` | 히스토리가 쌓인 터미널 창 | 높이로 스크롤백하고 아래 줄이 떠오른다 | 더 많은 줄이 뜬다 | CLI, 로그, 개발자 문서 |
| `drawer` / `Drawer` | 서랍 3칸 캐비닛 | 높이로 서랍을 골라 빼면 칸막이 두 개만 있다 | 더 많이 빠진다 | 빈 상태(empty state), 보관함 |
| `basket` / `Basket` | 손잡이 달린 빈 철망 장바구니 | 포인터 쪽으로 기울고 손잡이가 늦게 따라온다 | 더 기운다 | 빈 장바구니, 커머스 |
| `plot` / `Plot` | 데이터 없는 막대 차트(평평한 탭 7개) | 쓸고 지나가면 살짝 올랐다가 0으로 떨어진다 | 더 높이 오른다 | 데이터 없음, 대시보드 빈 상태 |

## 인프라·보안

| 함수 / 컴포넌트 | 무엇 | 포인터 반응 | intensity ↑ | 어울리는 화면 |
| --- | --- | --- | --- | --- |
| `cabinet` / `Cabinet` | 블레이드 12개 랙 | 높이에 가까운 블레이드가 빠진다 | 더 많이 빠진다 | 서버, 호스팅 |
| `vault` / `Vault` | 다이얼과 볼트 3개가 달린 금고 문 | 원을 그리면 다이얼이 돌고 40에서 볼트가 풀린다 | 다이얼 관성이 길어진다 | 보안, 비밀 관리 |
| `lockers` / `Lockers` | 사물함 12칸(하나는 살짝 열림) | 포인터 아래 문이 열리고 이전 문은 닫힌다 | 더 넓게 열린다 | 저장소, 권한 |
| `padlock` / `Padlock` | 자물쇠 | 다가가면 고리가 올라와 열린다 | 더 크게 열린다 | 로그인, 잠금 해제 |
| `patch` / `Patch` | 포트 24개 패치 패널과 케이블 | 포인터 아래 케이블이 들리고 이웃이 비켜선다 | 더 넓게 기운다 | 네트워크, 연동 |
| `dish` / `Dish` | 2축 짐벌 위 파라볼라 안테나 | 포인터를 겨누고 스프링처럼 따라온다 | 더 크게 돈다 | 수신, 모니터링 |
| `router` / `Router` | 안테나 달린 공유기 | 안테나가 포인터 쪽으로 기운다(가까울수록 많이) | 더 많은 안테나가 기운다 | 연결, Wi-Fi, 상태 |
| `hub` / `Hub` | 허브와 점선 링크로 이어진 타일 8개 | 포인터 아래 타일이 솟고 링크가 실선이 된다 | 더 높이 솟는다 | 통합, 연결 서비스 |
| `relay` / `Relay` | 가지 4개로 뻗은 타일 트리 | 리프까지 경로가 한 홉씩 켜진다 | 홉마다 더 오래 기다린다 | 라우팅, 전파, 워크플로 |
| `settle` / `Settle` | 허브 주위에 흩어진 타일 12개 | 다가가면 트리로 정렬되고 링크가 그려진다 | 더 멀리서부터 정렬된다 | 정리, 온보딩 완료 |

## 개발 도구

| 함수 / 컴포넌트 | 무엇 | 포인터 반응 | intensity ↑ | 어울리는 화면 |

| `branches` / `Branches` | main에서 갈라졌다 합쳐지는 커밋 그래프 | 포인터 아래 커밋과 그 이력이 솟는다 | 더 먼 이력까지 솟는다 | Git, 버전 관리 |

| `stack` / `Stack` | 프레임 5개 콜 스택 | 높이로 프레임을 고르면 위 프레임이 들려 열린다 | 더 높이 들린다 | 디버깅, 트레이스 |
